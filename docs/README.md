# Documentation index

Every document in the repository: what it owns, who reads it, and what change must update it. Each fact has one owner —
the document listed here — and every other document links to it instead of repeating it
([how we write](onboarding/11-documentation.md#how-we-write)). A new document gets a row here in the same pull request
(`tests/unit/docs/index.test.ts` fails otherwise).

New to AdminForge? Start with the [engineer onboarding guide](onboarding/README.md).
