# Glossary

The words we use for AdminForge's parts, the names they have in code and the labels people see in the portal. When you
name something new, use the term here; when a term is missing, add it with its identifier and label.

| Term                            | Meaning                                                                                                                                                                                                                        | Code identifier / UI label                                                                                                    |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| **AdminForge**                  | This portal: admin work on Entra ID, Microsoft 365, Intune, Defender and Azure through delegated access                                                                                                                        | `@adminforge/*` packages, `adminforge` CLI                                                                                    |
| **Approval**                    | A second person's decision a run or a write-capable schedule waits for; never the requester or someone the change benefits                                                                                                     | `approval:` on content and steps, table `approvals` · UI **Approvals** (`/approvals`)                                         |
| **Area**                        | The part of the estate a definition belongs to — a navigation section such as `identity`, `m365`, `exchange`, `azure`, `avd` or `billing` — and usually its content folder; a report's area places it in the Reports catalogue | id prefix, `nav.section`, a report's `area:` · UI the navigation section's label                                              |
| **Armed / write access**        | A time-boxed window, after a step-up sign-in to the Write app, in which an Operator's playbooks may change data. Shown in ember                                                                                                | `armed` (design token, session state), `POST /auth/arm` · UI **Arm write access**, **Disarm**                                 |
| **Audit log**                   | Append-only, hash-chained record of every state change; `pnpm adminforge audit verify` checks it                                                                                                                               | table `audit_events`, probe `probes.audit-chain` · UI **Audit** (`/audit`)                                                    |
| **Automation identity**         | The application identity unattended schedules run as; read-only by default, never used interactively                                                                                                                           | `identity: automation`, `AF_AUTOMATION_*` keys                                                                                |
| **BFF**                         | Backend-for-frontend: the API holds sessions and tokens so the browser never sees a Microsoft token                                                                                                                            | `portal/apps/api`                                                                                                             |
| **Catalogue (Reports)**         | Every report with filters, details and in-portal scheduling                                                                                                                                                                    | `GET /api/reports`, `routes/report-catalog.ts` · UI **Reports** (`/reports`)                                                  |
| **Code owner**                  | A reviewer named in `.github/CODEOWNERS` for sensitive paths; by team agreement also the people who publish, upgrade and provision                                                                                             | `.github/CODEOWNERS`                                                                                                          |
| **Content / definition**        | A YAML file in `portal/content` (page, report, playbook, schedule, …), validated by `@adminforge/schemas` and published to the database                                                                                        | `kind:` + `id:`, table `definitions`                                                                                          |
| **Correlation id / reference**  | The id on every response, error and audit event; what people read out when something fails                                                                                                                                     | `correlationId`, header `x-correlation-id` · UI **Reference**                                                                 |
| **CSRF header**                 | Required on every non-GET `/api` call (and the state-changing `/auth` POSTs)                                                                                                                                                   | `X-AdminForge-CSRF`                                                                                                           |
| **Cross-table join**            | A Resource Graph `join` to a table other than the query's own; the limits are [CLAUDE.md](../../CLAUDE.md) rule 14                                                                                                             | —                                                                                                                             |
| **Datasource**                  | A content-declared request (Graph, ARM, Resource Graph, Log Analytics, runner, …) plus an optional `transform`                                                                                                                 | `datasources:` · `POST /api/datasources/execute-many`                                                                         |
| **Delegated**                   | Acting as the signed-in person with their own permissions (the Read and Write apps)                                                                                                                                            | —                                                                                                                             |
| **Dry run**                     | A playbook's simulated run: reads run, writes become a plan of exactly what would change, before confirming                                                                                                                    | `dryRun: true`, `dryRunOutput:` · UI **Preview (dry run)**, "Dry run · nothing changed"                                       |
| **Emergency stop**              | A switch that pauses all changes and/or all automation, audited                                                                                                                                                                | UI Admin → Settings → **Emergency stop**                                                                                      |
| **Fixture**                     | Synthetic Microsoft response used in mock mode and tests (`tests/fixtures/`); `Example Org`, `example.com`                                                                                                                     | `DATA_MODE=fixtures`, `// af:<id>` query variants                                                                             |
| **Guards**                      | Tests that block secrets, your tenant's values and raw colours in committable text files; run by the pre-commit hook (tenant values are checked only there) and in CI                                                          | `tests/guards/`, `pnpm guard`                                                                                                 |
| **Licence gate**                | `requires.licences`: the UI explains "Requires …" instead of failing when the tenant lacks a licence                                                                                                                           | `requires.licences`, `licenceGate` widget, `LicenceGatePanel` · UI "Requires …"                                               |
| **Mock mode**                   | AdminForge with a fake sign-in, fixtures and in-memory state                                                                                                                                                                   | `AUTH_MODE=mock DATA_MODE=fixtures` · UI the dev toolbar                                                                      |
| **OPERATIONAL sweep**           | A KQL probe that watches service health rather than configuration runs on the 15-minute or hourly sweep instead of the 6-hourly configuration sweep                                                                            | `OPERATIONAL` in `tests/content/probes-schedules.test.ts`                                                                     |
| **Outbound executor**           | The only path to Microsoft: request policy, tokens, provenance, limits, error mapping                                                                                                                                          | `ctx.outbound`                                                                                                                |
| **Playbook / runbook**          | A declared change (inputs → dry run → confirm → steps) / a guided procedure of playbooks and manual steps                                                                                                                      | `kind: playbook` / `kind: runbook`, table `runs` · UI **Runs**                                                                |
| **Portal roles**                | App roles granted through groups                                                                                                                                                                                               | `Portal.Reader`, `Portal.Operator`, `Playbook.Approver`, `Playbook.Author`, `Portal.Admin`                                    |
| **Portal schedule**             | A report schedule an Operator created in the portal (stored in the database) rather than in content                                                                                                                            | id `portal.*`, `source: portal`                                                                                               |
| **Preview (definition)**        | A definition not yet confirmed to work against a live tenant; it runs as usual and says so. Not a dry run                                                                                                                      | `preview: true` · UI a quiet **Preview** badge; `adminforge validate` lists them                                              |
| **Probe**                       | A synthetic or KQL configuration check run by a schedule                                                                                                                                                                       | `kind: probe`, table `probe_results` · UI **Synthetic monitoring** (`/monitoring`); "Configuration checks (KQL)" in schedules |
| **Probe group**                 | The service a probe watches (a navigation section key, or `platform`); Synthetic monitoring, the status mark on each navigation section's row and `probeStatus` widgets group by it                                            | `group:`, `/monitoring?group=<key>` · UI "Service checks · <section>"                                                         |
| **Protected objects**           | AdminForge's own apps, the principals holding its roles and listed accounts — writes naming them are refused                                                                                                                   | codes `protected_object`, `user_not_by_id`                                                                                    |
| **Publish**                     | Reviewed content (in the pod, from the app image) → the database, picked up by the running API within a second                                                                                                                 | `adminforge publish`                                                                                                          |
| **Read app / Write app**        | The two delegated app registrations: everyday reading; changes while armed                                                                                                                                                     | —                                                                                                                             |
| **Remedy**                      | What to do when a probe warns or fails — shown with its result, next to its `link` (where to act)                                                                                                                              | `remedy:` · UI **What to do**                                                                                                 |
| **Request policy**              | Default-deny rules on outbound calls: only reads in read mode, declared writes when armed                                                                                                                                      | —                                                                                                                             |
| **Retired definition**          | Out of use and out of navigation, kept in git and the database for history; nothing active may point at it                                                                                                                     | `status: retired` + a version bump                                                                                            |
| **Runner**                      | The PowerShell sidecar for Exchange, Teams and SharePoint: pinned scripts, sealed tokens, signed jobs                                                                                                                          | `portal/apps/runner`, `source: runner`, step `type: runner`                                                                   |
| **Skill**                       | A Claude Code recipe for one extension point                                                                                                                                                                                   | `.claude/skills/<name>/SKILL.md`                                                                                              |
| **Steel / daylight / contrast** | The themes; screenshots are reviewed in steel and daylight                                                                                                                                                                     | `steel`, `daylight`, `contrast`                                                                                               |
| **Step-up**                     | The fresh sign-in (and authentication context, when configured) needed to arm write access                                                                                                                                     | `WRITE_AUTH_CONTEXT`                                                                                                          |
| **Validation tenant**           | The non-production tenant used for live tests; writes only on `AF-Test-*` objects                                                                                                                                              | `tests/live/`                                                                                                                 |
| **What it found**               | The rows behind a probe's result (which certificates, which servers), shown in its detail on Synthetic monitoring — to Operators only, since the automation identity collected them                                            | `fields`, `detailsLimit` · UI **What it found**                                                                               |

## Spelling

New identifiers and UI text use **British spelling**: _licence_ (the noun), _catalogue_, _utilisation_, _organisation_,
_colour_, _behaviour_. Existing ids, routes, table and file names keep the spelling they have — saved views,
schedules, audit records and links depend on them — so these are the listed exceptions:

| Identifier                                                                      | Where                                                                  | Why it stays                                                                                |
| ------------------------------------------------------------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `licenseThreshold` (probe kind), `LicenseThresholdCheck`                        | `@adminforge/schemas`, the licence-seat probes, the API's probe checks | Renaming needs a schema alias, every probe using it and their tests — for a spelling        |
| `report-catalog.ts`, `catalog.ts`, `ReportCatalog*`                             | API route and service, web, schemas                                    | File and type names; the UI says "catalogue"                                                |
| `m365.licence-utilization` and its `utilization` field                          | `portal/content/reports/m365/`                                         | The id is referenced by schedules and saved views; its title may change with a version bump |
| Microsoft's and libraries' names (`assignedLicenses`, `/organization`, `color`) | Graph, ARM, CSS, ECharts                                               | Not ours to rename                                                                          |
